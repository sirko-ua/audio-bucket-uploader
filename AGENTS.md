# Repository instructions

- Write simple, understandable code.
- Do not attempt to catch or predict every possible exception. Let unexpected failures raise, or log them with enough context to diagnose the problem.
- Respect the `--verbose` setting: keep normal output concise and put diagnostic detail behind verbose mode.
- Keep the uploader script in one file for simplicity.
- Use meaningful variable and function names. Add comments or docstrings where the intent is not obvious.
- Do not write tests unless the user explicitly asks for them.
